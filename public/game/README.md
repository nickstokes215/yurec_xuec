# Игры (`game/`)

Обложки хабов и сами движки (canvas, подключаются со страниц `/game/av` и `/game/ark`).

- `quest.jpg` — Юрцовский квест
- `crosswords.jpg` — список кроссвордов
- `av.jpg` + `av-game.js` — Помойкобол
- `ark.jpg` + `ark-game.js` — Алконоид
- `svoya.jpg` — обложка «Юрца игра»
- `svoya-q.json` — колода: 25 тем, 10 000 вопросов. Сборка: `python3 scripts/pack-svoya.py`

Обложки отдельных сеток и уровней квеста — в `../covers/`.
