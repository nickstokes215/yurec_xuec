# public/ — то, что видит приложение

Картинки, звуки и игровые движки сборника «Жизнь Юрца». Сюда смотрит веб и APK
(`scripts/build-apk.sh` копирует файлы в Android assets).

| Папка | Зачем |
|---|---|
| `characters/` | Аватары героев. Имя файла = id в `src/data/characters.json` |
| `covers/` | Обложки кроссвордов (`crossword-1.jpg`…`crossword-20.jpg`), уровней квеста (`level-1.jpg`…`level-5.jpg`) и цитатника |
| `press/` | Страницы газеты: `p47-1.jpg` выпуск №47, `p52-1.jpg` выпуск №52 |
| `thumbs/` | Миниатюры серий и песен: `s01e00.jpg`, тизеры, `song-*.jpg` |
| `media/` | Плитки разделов медиа и свои обложки (шортсы, фото, «Знак в голове») |
| `banners/` | Шапки чипов сборника: серии / песни / визиты / бонусы |
| `quotes/` | Голосовые цитаты героев (mp3) |
| `icons/` | Иконки приложения: comedy / horror |
| `game/` | Обложки хабов и движки Помойкобола (`av-game.js`) и Алконоида (`ark-game.js`) |
| `donate/` | Картинки экрана доната |
| `achievements/` | Зашквары двора: обложка, закрытая медаль, картинки ачивок |
| `maps/` | Карта двора, Петербург, квартира |

Корень `public/`: `og.jpg` (шапка «все»), `easter-horror.jpg`, `yurec-icon.jpg`, `favicon.svg`, `yurec_xuec.apk` (скачать сборку).

`__grok/` — служебное для превью/PWA, руками не трогать.
