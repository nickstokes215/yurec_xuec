# assets/

`www/` — двор, который открывает WebView. Не исходник: его кладёт `scripts/pack-www.sh` из `public/` + `src/data`.

Править руками `www/data.js` бессмысленно — следующий pack затрёт. `index.html` и `app.js` живут здесь постоянно: это телефонный интерфейс, не React.

После pack коммить www вместе с json/картинками, иначе сайт и APK разъедутся.
