# src/ — код сборника

| Папка | Зачем |
|---|---|
| `routes/` | Экраны. Имя файла ≈ адрес: `game.av.tsx` → `/game/av` |
| `components/` | Оболочка, кроссворд, карта двора, оффлайн, салют, дождь, звездопад |
| `data/` | JSON текстов и хелперы. Карта — `data/README.md` |
| `lib/` | Хуки и утилиты. Карта — `lib/README.md` |
| `styles.css` | Тема двора |
| `router.tsx`, `routeTree.gen.ts` | Маршруты TanStack Router |

`lib/auth/` — заготовка Better Auth из каркаса. Сборник ходит без аккаунтов: лицензия — локальное слово, не логин.
