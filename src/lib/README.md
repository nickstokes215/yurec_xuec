# src/lib/ — память двора и служебное

Хуки читают `localStorage`. Бэкап (`use-backup.ts`) снимает те же ключи одним файлом.

## Сборник

| Файл | Зачем |
|---|---|
| `use-settings.ts` | Тема, вибрация, звук, не гасить экран, ярлык, имя приложения, тумблеры меню, виджет цитаты, ссылки поддержки |
| `use-theme.ts` | Свет / тьма / система, пишет класс на `<html>` |
| `use-paid.ts` | Лицензия после доната. Событие `yurec-license-changed` |
| `license-key.ts` | Один ввод: сначала слово разработчика, потом лицензия |
| `secret-gate.ts` | SHA-256(соль + слово). Самих слов в репозитории нет. Чит-коды к играм — те же хеши |
| `use-read.ts` | Какие серии отмечены «прочитано» |
| `use-library.ts` | «Продолжить» на главной, закладки |
| `use-sort.ts` | Порядок карточек: как в канале / алфавит / новые |
| `use-char-order.ts` | Перестановка героев долгим тапом |
| `use-game-order.ts` | Перестановка игр на хабе |
| `use-game.ts` | Концовки квеста и кроссвордов |
| `game-stats.ts` | Помойкобол / Алконоид: победы, лучшее время |
| `svoya-store.ts` | Текущая партия «Юрца игра» |
| `svoya-stats.ts` | Таблица лучших и число партий |
| `use-achievements.ts` | Зашквары: что открыто и когда |
| `use-passport.ts` | Сводка для экрана «Паспорт двора» |
| `use-backup.ts` | Экспорт / импорт JSON справки |
| `offline.ts` | Список и качка оффлайн-видео с Яндекс.Диска |
| `zoom.ts` | Лупа по обложкам |
| `story-format.ts` | Абзацы, цитаты, жирные места в читалке |
| `library.ts` | Мелочи каталога для главной |
| `utils.ts` | `cn()` — склейка классов |
| `yurec-brain.ts` | Локальный Юрец без сети: настроение, заготовки |
| `yurec-chat.ts` | Запрос к модели, если есть ключ |
| `yurec-chat-store.ts` | История чата, шаринг, ярлык |

## Каркас превью (не двор)

| Файл | Зачем |
|---|---|
| `auth/` | Better Auth. В сборнике выключен |
| `db.ts` | Postgres / PGLite |
| `error-component.tsx` | Красный экран ошибки роутера |
| `og/` | Карточка шаринга для Grok |
| `preview-host-bridge.ts` | Связь с превью-хром Grok |
| `preview-embedder-origin.ts` | Разрешённый origin превью |
| `multiplayer/` | Заготовка WebRTC, не используется |

События окна, на которые подписан паспорт: `yurec-progress`, `yurec-av-wins`, `yurec-ark-wins`, `yurec-svoya`, `yurec-endings`, `yurec-license-changed`.
