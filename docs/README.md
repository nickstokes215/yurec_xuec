# docs/ — карта и исходники

| Путь | Зачем |
|---|---|
| `originals/` | Исходные картинки и звуки, из которых собраны файлы в `public/`. В APK не входят |
| этот README | Точка входа |

Код приложения эти файлы не читает. Нужны, чтобы через год вспомнить, откуда взялась обложка.

Если выкладываешь исходники в открытый доступ и хочешь репозиторий легче — папку `originals/` можно не публиковать: в `public/` уже лежат сжатые рабочие копии.
