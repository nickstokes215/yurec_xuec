# Исходники картинок и голосов

Сюда сложены оригиналы, которые приходили вложениями: обложки героев, кроссвордов, доната, иконки, mp3 цитат.

Рабочие файлы приложения — в `public/` (латиница в имени, сжатый JPEG). Эти оригиналы сборник не подключает.

Не класть сюда: скриншоты QA, `.jks`, пароли, APK.
